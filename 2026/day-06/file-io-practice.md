# Day 06 – Linux Fundamentals: Read and Write Text Files

Below basic commands are useful for reading and writing the text files.


You will create a small text file and practice:
- Creating a file : By using touch created a notes.txt and performed the commands.
- Writing text to a file : echo "Line 1" > notes.txt
- Appending new lines : echo "Line 2" >> notes.txt`
- Reading the file : cat notes.txt
- to see top 2 lines of the file: head -n 2 notes.txt`
- To see last 2 line of the file: tail -n 2 notes.txt
